# Sistema de Cálculo Básico

**Autor:** Guido Bastiani

**Asignatura:** Fundamentos de Ingeniería de Software II

## Descripción del proyecto

Este proyecto tiene como objetivo practicar el control de versiones utilizando Git y GitHub.

Se desarrollará un componente inicial de cálculo que evolucionará mediante cambios controlados, utilizando commits, ramas, fusiones y etiquetas de versiones.

La primera versión contiene una descripción del proyecto y un script principal básico.
